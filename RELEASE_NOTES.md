## Descargas / Downloads

| Sistema / System | Archivo / File |
|---|---|
| Windows 10/11 | `chismaker-windows.exe` |
| macOS (Apple Silicon: M1/M2/M3/M4) | `chismaker-macos.zip` |

No necesitás instalar Python. / No Python installation needed.

## Aviso: las apps no están firmadas / Notice: the apps are not signed

Por eso Windows y macOS muestran una advertencia la primera vez. Es normal; el código es abierto y está en este repositorio.
That is why Windows and macOS show a warning the first time. This is expected; the source code is open in this repository.

### Windows
1. Doble clic en `chismaker-windows.exe`.
2. Si aparece "Windows protegió su PC": clic en **Más información** → **Ejecutar de todas formas**.
   (If you see "Windows protected your PC": **More info** → **Run anyway**.)

### macOS
1. Descomprimí `chismaker-macos.zip` y abrí `SuperChis Chismaker.app` (si querés, arrastrala a Aplicaciones).
2. Si macOS la bloquea: **Ajustes del Sistema → Privacidad y seguridad**, bajá hasta el aviso sobre "SuperChis Chismaker" y pulsá **Abrir de todos modos**.
   (If blocked: **System Settings → Privacy & Security** → **Open Anyway**.)
3. Alternativa en la Terminal: `xattr -dr com.apple.quarantine "SuperChis Chismaker.app"`

Solo para Macs con chip Apple Silicon. En Macs Intel ejecutá desde el código fuente (ver README).
Apple Silicon Macs only. On Intel Macs, run from source (see README).
